# Project Overview

T001-PS-008 is a beginner-friendly Python project for processing mutual fund orders. The planned system covers scheme and investor records, NAV and holiday data, orders, and investment lots. SQLite and transaction engines are future work; they are not part of Day 1 or Day 2.

The current Day 1 foundation provides basic data classes. Day 2 provides business-day helpers and the NAV date rules BR-01 and BR-02. CSV values are illustrative sample data only and are not real market data.

Run the program from the repository root with `python -m src.main`. Run tests with `python -m pytest -v`.
